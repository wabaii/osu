# click the circles: an osu! motion graphic

A 56-second, 1080p60 motion graphic about the rhythm game [osu!](https://osu.ppy.sh), with its own
synthesised soundtrack. Everything you see and hear is generated by code from a beat-synced
timeline. The only external visual asset is the official cookie logo.

**▶ Video: [`output/osu-motion-graphic.mp4`](output/osu-motion-graphic.mp4)**

## How it's made

- `src/`: a deterministic HTML-canvas animation. `renderFrame(t)` draws any moment of the video.
  - `js/core.js`: beat grid (160 BPM), easing, colour, kinetic type, rising triangles.
  - `js/objects.js`: vector hit circles, approach circles, sliders, spinners, follow points,
    judgements, cursor and trail, and a small `Beatmap` class. The class works out combos and key
    presses, and emits audio cues for every hit.
  - `js/scenes.js`: the eight scenes and the gameplay HUD. `js/main.js`: timeline, transitions,
    preview player.
- `scripts/render.mjs`: serves `src/`, drives headless Chromium with Playwright, renders frames in
  parallel workers, and encodes with ffmpeg (H.264, CRF 16, AAC 256k).
- `scripts/make_audio.py`: numpy/scipy synth. It plays the "royal road" progression in D major
  (kick, clap, hats, supersaw chords, plucks, chiptune arp, lead, pads, risers). Hitsounds are
  synthesised and placed from the animation's own cue list, panned by on-screen x position as in
  osu!.

## Build it yourself

Requirements: Node 18+, Playwright with Chromium, Python 3 with numpy and scipy, and ffmpeg.

```sh
npm run cues     # export hitsound timing from the animation  -> build/cues.json
npm run audio    # synthesise the soundtrack                  -> build/soundtrack.wav
npm run video    # render 3360 frames + mux audio             -> output/osu-motion-graphic.mp4
npm run stills -- 6.3,31,44   # spot-check individual moments  -> build/stills/
npm run preview  # http://localhost:8080/src/index.html, plays in real time with audio
```
